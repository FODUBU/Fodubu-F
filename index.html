Node Validator Setup

To connect your local Pi Node to the FODUBU test network and begin validating smart contracts:

  • Ensure your local Docker container is synchronized on port 31401.
  • Reference our pi.toml for the active Testnet Validator Public Keys.
  • Monitor Soroban ledger executions via the local Horizon API.
